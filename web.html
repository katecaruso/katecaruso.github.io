Web Design

Interactive Web Activities

For this project, I used HTML, CSS, and JavaScript to create two interactive activities based on the television show Friends: a trivia quiz and a drag-and-drop activity. I also created an AI-assisted version of the drag-and-drop activity to compare traditional web development with AI-assisted development.

Interactive Trivia Quiz

View Trivia Quiz

For the traditional approach, I modified the HTML and JavaScript files provided in the course materials using Notepad. I replaced the original questions with ten Friends trivia questions, updated the answer choices and correct-answer information, and customized the feedback displayed to users. I also adjusted the spacing and formatting to make the quiz easier to read.

I changed the background to lavender as a nod to the purple door in Monica's apartment and used Georgia for the question-and-answer text. After testing all ten questions, I adjusted the dimensions of the question box to reduce empty space and prevent questions from wrapping onto additional lines. I also added a gold border inspired by the frame around Monica's peephole. This activity gave me more practice modifying HTML, CSS, and JavaScript and seeing how relatively small changes can improve the appearance and usability of a webpage.

Drag-and-Drop Activity

View Drag-and-Drop Activity

For the second activity, I created a Friends-themed drag-and-drop exercise using HTML, CSS, and JavaScript. This project gave me another opportunity to explore how web technologies can be used to create interactive learning experiences rather than simply present information.

Working on the activity helped me better understand how the structure, appearance, and interactive behavior of a webpage work together. I also gained more experience testing an activity from the learner's perspective and making adjustments to improve its usability.

AI-Assisted Drag-and-Drop Activity

View AI-Assisted Activity

For the AI-assisted portion of the assignment, I used AI to help create another version of my Friends drag-and-drop activity. This allowed me to compare the experience of working directly with HTML, CSS, and JavaScript with using AI to assist in developing an interactive webpage.

AI made parts of the development process faster, but I still needed to review the results, test the activity, and make sure it worked as intended. Comparing the two approaches reinforced the importance of understanding the underlying code, even when AI can help generate it.
